## Setup

Install dependencies in both apps:

```bash
cd client && npm install
cd ../server && npm install
```

Create `server/.env`:

```
MONGO_URI=your_atlas_connection_string
```

Add your IP under Network Access in MongoDB Atlas.

## Running

Two terminals.

Frontend:
```bash
cd client
npm run dev        # http://localhost:5173
```

Backend:
```bash
cd server
node server.js     # http://localhost:9000
```


## API

| Method | Endpoint  | Body                                       | Success | Errors        |
|--------|-----------|--------------------------------------------|---------|---------------|
| POST   | `/signup` | `f_name`, `l_name`, `username`, `password` | 201     | 400, 409, 500 |
| POST   | `/login`  | `username`, `password`                     | 200     | 400, 401, 500 |

All responses are JSON: `{ "message": "..." }`

## Data model

Database `pa2`, collection `users`:

```js
{
  _id: ObjectId,   // generated by MongoDB
  f_name: String,
  l_name: String,
  username: String,  
  password: String
}
